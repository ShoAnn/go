# What i've learned from this project

- The go way of building REST API with just it's **standard library**
- Using **repository design patten** in a Go web project
- Using **postgresql** in go with **pgx** for db driver and **sqlc** for query builder
- Validation using struct decorators from [go-playground/validator/v10](https://github.com/go-playground/validator)
- how to **Unit test** using the ```testing``` and ```httptest```
- integration test using [testcontainers](https://github.com/testcontainers/testcontainers-go)
